Play Taap Taap on a 24-square board with Classic, Rush, and Zen modes, accelerating targets, combos, lives, shields, and slow-motion bonuses. Choose Studio, Sakura, or Cyber themes on iPhone, iPad, and native macOS.

### App downloads

| Asset | Use |
| --- | --- |
| **TaapTaap-macOS-universal.zip** | Mac app for Apple Silicon and Intel, macOS 14+. Ad-hoc signed; not notarized. |
| **TaapTaap-iOS-iPadOS-unsigned.ipa** | iPhone/iPad device package, iOS 17+. **Requires your own signing and provisioning before installation.** |
| **TaapTaap-iOS-Simulator.zip** | Run in Xcode's iPhone/iPad simulator on a Mac. |
| **INSTALL.md** | Installation instructions and signing limitations. |
| **SHA256SUMS.txt** | Checksums for the downloads. |

For Mac, unzip the download and move TaapTaap.app into Applications. If macOS blocks this unnotarized preview, use System Settings → Privacy & Security → Open Anyway after attempting to open it, only if you trust this release.

There is no TestFlight or App Store distribution in this preview. The unsigned IPA is not a one-tap iPhone/iPad installer. See INSTALL.md for the Xcode device setup.

Release checks cover the core game rules, universal Mac and simulator architectures, Mac signing and sandbox entitlement, and a Mac launch smoke test. Physical-device playtesting remains recommended.
